外部请求如何进入 Runtime

本页不只列入口，而是逐字段解释：调用者的自然语言、结构参数和权限，如何被收敛为 Runtime 可接受的运行信封；哪些信息被保留，哪些能力被故意挡在边界外。

本页结论：入口转换的主要损失不是文本摘要，而是权力缩减。父 Agent、JSON-RPC 客户端和 CLI 可以描述任务，却不能把 primitive GUI 权力、模型自授能力或未绑定审批直接送进内核。

TaskRequest / UserRequest→TaskSpec（可选）→RunRequest→TaskRuntimeService / TaskRunner→RunCoordinator
01-A

外部任务描述 → TaskRequest / UserRequest

输入 INPUT

自然语言、caller/channel/locale、目标引用、附件/会话/profile 引用，以及调用边界提供的约束和能力。

→

输出 OUTPUT

UserRequest 保存原文与来源引用；任务 API 使用 TaskRequest 表达任务级提交参数。

转换者与规则：API/CLI/父 Agent 适配层只做字段封装和类型校验；引用型上下文保留 ref，不在入口静默展开为全文。
输入字段转换操作输出字段下游用途
用户原文原样复制raw_textSourceLedger 与 intent compiler
附件/会话/profile引用化*_refs来源追踪，不默认泄漏内容
调用者身份与渠道显式字段caller/channel/locale审计与解析上下文

保留语义

原始文本、来源类别、引用身份、调用上下文和明确提供的限制。

可能的语义损失

引用只暴露标签/哈希时，附件细节与跨来源关系暂时不可见；调用者未结构化表达的隐含权限不会被推断。

风险与防护

风险是模型缺少必要背景或误解指代。防护是保留 source ref、后续澄清，而非把未读取内容当成已知。

失败出口

字段非法时拒绝输入；语义材料不足时进入 NEEDS_CLARIFICATION，不会继续执行。

01-B

TaskSpec / 外层参数 → RunRequest

输入 INPUT

task_id、goal、target、constraints、capabilities，以及已经编译的可选 TaskSpec。

→

输出 OUTPUT

不可变 RunRequest，作为 Coordinator 整次运行的入口信封。

转换者与规则：RunRequest.__post_init__ 校验 identity；存在 TaskSpec 时，task_id 与 goal 必须匹配规范任务，外层字段不能覆盖它。
输入转换操作输出权威变化
task_id / goal一致性绑定RunRequest identityTaskSpec 优先
constraints冻结复制运行策略输入Planner 不可放宽
capabilities入口授予granted capability 上限模型不可新增
target信封字段环境目标后续仍需 scope 校验

保留语义

任务身份、规范目标、约束、能力上限与目标环境。

可能的语义损失

外层 goal 与 TaskSpec 不一致时不会合并两个版本；外层多余语义被拒绝而非折中。能力集合只会缩小，不会把“用户想做”自动转换为“系统有权做”。

风险与防护

拒绝合并可能让调用者觉得信息“消失”，但这是防止信封覆盖规范授权的有意丢弃；通过 mismatch error 显式暴露。

失败出口

identity/goal 冲突直接构造失败；能力不足在 preflight 进入 CAPABILITY_DENIED。

01-C

任务级工具调用 → Runtime 执行与查询

输入 INPUT

gui_submit_task、execute、approve、revise、cancel、result、evidence、trace 等任务级工具调用。

→

输出 OUTPUT

TaskRuntimeService 的任务记录、运行结果或证据视图；执行路径最终委托给 TaskRunner/RunCoordinator。

转换者与规则：TaskToolAdapter 将外部 schema 映射到 service 方法；external_protocol.py 再把 JSON-RPC tools/call 映射到该适配器。

保留语义

任务生命周期意图、revision、审批/澄清操作、结果与证据查询。

可能的语义损失

primitive click/type/observe 不在工具面中；父 Agent 的内部思考、局部计划与任意坐标不会传播到 Runtime。

风险与防护

父 Agent 无法微操可能降低某些场景灵活性，但避免绕过 TaskSpec、审批和验证。TaskSpec revision 仅在等待澄清时更新，能力只能收窄。

失败出口

非法生命周期操作返回明确状态错误；审批不匹配具体 run/contract/page revision 时不生效。

本页语义损失账本

转换边类型不可见或丢弃内容是否可恢复控制
外部上下文 → UserRequest有界裁剪引用对象正文暂不展开可按 ref 补取或澄清source refs
外层信封 → RunRequest有意丢弃与 TaskSpec 冲突的 goal/identity需新 revision构造校验
父 Agent → Task tools最小权限primitive GUI 动作与任意坐标不应恢复工具面隔离
