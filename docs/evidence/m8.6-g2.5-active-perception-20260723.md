## Implemented boundary

- Added strict Runtime-owned contracts for evidence gaps, declared read-only
  probe capabilities, commands/plans, transport receipts, and evidence-based
  resolutions.
- Added one deterministic `ActivePerceptionController`. Hard gates cover
  availability, read-only authority, task relevance, source compatibility,
  observation/time/model/cost/artifact budgets, and attempted same-gap probes.
- Probe ordering handles blocking/risk first, then independent conflict source,
  declared source preference, cost, and latency. Confidence remains source
  local and is never numerically fused across uncalibrated sources.
- Added normal-observation gap extraction, including proactive unresolved-target
  and task-required visual/spatial/device evidence gaps. Sufficient structural
  paths remain probe-free.
- Integrated the same controller into ordinary observation, preflight,
  inconclusive-verification evidence repair, and existing lower-half recovery
  post-state inspection.
- Every successful targeted capture must use a fresh coherent observation epoch
  across source observations, assertions, and grounding candidates. Resolution
  requires re-arbitrated evidence; a successful transport receipt is not proof.
- A material unresolved gap blocks effectful execution. Verification and
  recovery inspection acquire evidence without blindly repeating the effect.
- `StateKernel` remains the sole mutable run-state authority. The controller
  only returns typed immutable decisions.
