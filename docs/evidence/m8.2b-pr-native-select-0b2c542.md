# M8.2B Native Select Binding Checkpoint

This is a further M8.2B checkpoint, not an M8.2B completion claim.

At `0b2c542`, the DOM adapter retained a native option's owning `<select>`
identity. When a general planner semantically activates that option, the
BrowserGym adapter deterministically binds the contract to typed
`select_option(owner_bid, option_value)` rather than trying to click an
invisible `<option>`. The rule is based solely on native DOM ownership; it has
no task id, regex, selector, or benchmark-specific solver branch.
