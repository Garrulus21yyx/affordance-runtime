## Runtime change

The default semantic compiler registry now declares
`typed-suggestion-selection-v1` separately from
`explicit-form-field-binding-v1`:

- exact form assignments accept only literals grammatically bound to writable
  fields or explicit shared-field cardinality;
- `starts with` and optional `ends with` relations produce a typed suggestion
  obligation over a uniquely bound autocomplete control;
- the compiler establishes the prefix, activates one current matching semantic
  option, and exposes one submit-like terminal after a longer current value
  satisfies the relation;
- multiple controls or matching options without a unique semantic binding fall
  through to System 2;
- the Planner emits only semantic target ids and `type_text` / `activate`.

Shared runtime code contains no task id, URL, suite, benchmark, model, Prompt,
selector, raw DOM handle, or budget override.
