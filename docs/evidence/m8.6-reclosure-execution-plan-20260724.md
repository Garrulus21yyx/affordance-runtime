- `RunCoordinator` remains the only authoritative state and trace committer.
- `coordinator.py` is feature-frozen; the ratchet has decreased from the audited
  3813-line / 29-method surface to 3732 lines / 26 methods and may only decrease.

  focused non-BrowserGym tests.
- Downstream code may narrow but never expand capability, observation,
  model-call, cost, or latency authority.
- Recovery success requires a real owning-port result with before/after
  evidence; an intended or no-op change is not progress.
- Synthetic G5 ledgers remain schema tests only. Closure requires fresh,
  immutable, profile-separated Runtime rollouts.
- No `.env`, credentials, remote provider, GitHub Action, external suite,
  benchmark score promotion, push, microservice, or task-family solver is
  authorized by this plan.
