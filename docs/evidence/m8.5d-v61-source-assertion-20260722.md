# M8.5D v61 SourceAssertion and Active Perception Evidence

Date: 2026-07-22

## Scope

This local slice implements the plan's rule-first multi-source assertion and
targeted active-perception boundary. It does not give any source or model
authority to execute actions.

## Typed assertion boundary

`SourceAssertion` retains entity/property identity, typed value and unit,
source, coherent observation epoch, environment/page revision, observed and
expiry times, source-local confidence semantics, parser/schema identity,
materiality, and evidence references.

The arbiter returns one of:

- `ACCEPTED`: current evidence agrees after typed normalization, or a declared
  property-specific authority resolves lower-authority disagreement.
- `REOBSERVE`: a material disagreement can be addressed within the bounded
  active-perception budget.
- `CONFLICT`: current material evidence remains contradictory and no request
  budget is available.
- `INCONCLUSIVE`: evidence is invalid, stale, expired, or insufficient.

Confidence is compared only within one source. A high DOM confidence does not
override lower-confidence visual evidence for a visual property. WoT and API
share the authoritative device-state tier, so disagreement between them
triggers re-observation rather than arbitrary source precedence.

## Route and active-perception integration

- `SourceAssertionOrchestrator.reconcile_snapshot()` attaches raw claims,
  decisions, accepted state, unresolved material conflicts, and targeted
  requests to one coherent `BrowserSnapshot`.
- Accepted values enter `UnifiedAffordance.accepted_state`.
- `REOBSERVE`, `CONFLICT`, and material `INCONCLUSIVE` decisions enter
  `UnifiedAffordance.unresolved_conflicts`; the existing Unified Route hard gate
  rejects the target before contract construction.
- Coordinator calls an optional `capture_targeted(requests)` observation port.
  The port must return a complete coherent `BrowserSnapshot`, not a partial
  locator or mutable patch.
- Targeted captures have an independent bounded budget. Repeated unresolved
  requests emit `TargetedPerceptionBudgetExhausted` and cannot loop forever.
- Observations, assertion provenance, arbitration, request, fulfillment, and
  budget/unavailable outcomes have separate trace nodes. Trace payloads retain
  evidence references but omit raw assertion values.
