## Residual diagnosis

The trace shows a generic semantic mismatch:

1. the explicit-form compiler treats the quoted prefix in “starts with 'Com'”
   as an exact final input value;
2. the runtime fills `Com` and the model selects the observed `Comoros` option;
3. the selected value no longer equals the exact obligation value, so the
   compiler fills `Com` again;
4. the cycle repeats until the 15-call model budget is exhausted.

The current FailureEnvelope correctly records the terminal symptom, but its
`required_evidence_present=false` does not express the stronger trace evidence
that the wrong constraint kind was compiled. The next repair boundary is a
typed distinction between exact field values and prefix/suggestion-selection
constraints, with generic negative controls. It is not a reason to increase
the model budget, change the Prompt, or add an autocomplete/task branch.

No full nightly or release rerun was started. The frozen release was not
resumed or modified. No GitHub Action ran, and `.env` was not read, printed,
staged, or uploaded.
