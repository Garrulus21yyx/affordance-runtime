# M8.2B v104 WorkArena Isolated Runtime Preflight

Date: 2026-07-22

## Gap

The documented WorkArena command claimed to inspect a dedicated
`browsergym-workarena` runtime, but the implementation inspected whichever
Python happened to launch the repository CLI. It could not select or record an
isolated interpreter and therefore did not prove the deployment boundary.

## Repair

- `AFFORDANCE_WORKARENA_PYTHON` and `--runtime-python` now select the dedicated
  interpreter; the durable default is
  `~/.venvs/affordance-workarena/bin/python`;
- the child probe records exact interpreter, Python, `browsergym-workarena`,
  Playwright, and L1 registration count;
- the repository `.venv`, Playwright other than 1.44.0, and any L1 count other
  than 33 fail closed;
- the probe child receives only `PATH` and `PYTHONIOENCODING`, never ServiceNow
  URL, username, password, pool contents, or access token;
- the parent records only `explicit_instance`, `custom_instance_pool`,
  `gated_instance_pool`, or `unconfigured`.

```bash
PYTHONPATH=src python -m affordance_runtime \
```

L1 registration. This is a deployment report, not a task failure or score.
