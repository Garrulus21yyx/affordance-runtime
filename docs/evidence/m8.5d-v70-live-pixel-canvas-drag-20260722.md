# M8.5D v70 Live Pixel-Grounded Canvas Drag Evidence

Date: 2026-07-22

## Scope

This closes the visually-grounded drag gap left open by the quota-limited v59
provider probe. It uses a deterministic local pixel detector rather than
claiming remote VLM availability.

## Real Chromium path

Chromium `151.0.7922.10` rendered a canvas-only board with a red source region
and green destination region. For every observation the diagnostic:

1. captures a real full-page PNG;
2. scans decoded screenshot pixels without reading DOM geometry;
3. derives current red and green bounding boxes;
4. creates separate typed visual `GroundingCandidate`s and semantic targets;
5. lets the planner emit only `DRAG(source_semantic_id,
   destination_semantic_id)`;
6. binds both current endpoint fingerprints, leases, snapshot ids, and the
   selected visual route in Core;
7. executes bounded mouse move/down/move/up through `VisualExecutor`;
8. observes the page again and verifies an independent canvas `mouseup` oracle.

Detected regions were:

- source `[80, 120, 50, 50]`;
- destination `[420, 100, 120, 120]`.

Final status was `done`, verification was `passed`, the receipt action was
`visual_drag`, the gesture contract was traced, the selected route was
`visual`, and the independent `window.dragged` oracle was true. Planner history
contained no x/y, bbox, bid, selector, or other low-level binding.
