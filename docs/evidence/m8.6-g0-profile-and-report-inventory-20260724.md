## Classification rule

Evidence is classified from its immutable source revision and reviewed active
code path, never reconstructed from a high score. A report created before
explicit profile/registry fields is not strict-generalist evidence. Dirty-tree,
targeted, partial, and stopped runs remain diagnostic regardless of outcome.

No historical artifact is rewritten. This inventory supplies the current
governance interpretation, while the original evidence file remains an exact
record of what its revision claimed.
