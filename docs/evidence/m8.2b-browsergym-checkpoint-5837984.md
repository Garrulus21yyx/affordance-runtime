# M8.2B Resumable BrowserGym Matrix Checkpoint

At `5837984`, Generalist BrowserGym matrices gained atomic per-episode
checkpoints and explicit `--resume` support.

The real Mistral PR profile first completed 18 episodes with:

```text
checkpoint_new_episode_count=18
checkpoint_reused_episode_count=0
run_complete=true
official_success_rate=0.8333
```

Re-running the same output directory with `--resume` took approximately 1.35
seconds and produced:

```text
checkpoint_new_episode_count=0
checkpoint_reused_episode_count=18
run_complete=true
observed_episode_count=18
official_success_rate=0.8333
```

The three existing `form-sequence` clarification outcomes were preserved as
runtime diagnostics; resume does not erase or reclassify failed episodes. Each
checkpoint is written through a temporary file and atomic replace. Only
episodes inside the selected task/seed matrix are eligible for reuse.

This enables long nightly/release matrices to be paused and continued without
silently dropping episodes. It does not itself complete those matrices.
