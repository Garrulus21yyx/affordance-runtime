# M8.2B Generalist BrowserGym PR Matrix Evidence

This is an in-progress M8.2B checkpoint, not an M8.2B completion claim.

At `0a7ff46`, `GeneralistLMPlanner` was run through the full Coordinator and
typed BrowserGym executor against the pinned BrowserGym 0.14.3 / MiniWoB++
`7fd85d71a4b60325c6585396ec4f48377d049838` environment. The planner used
the configured remote Mistral profile (`mistral-medium-3-5`); credentials and
raw model content are not recorded here.

## Reproduction

Run this from the isolated Python 3.12 BrowserGym environment after loading a
valid model profile:

```bash
LLM_ACTIVE_PROFILE=mistral LLM_PROFILE_FALLBACK_TO_LOCAL=false \
  affordance-runtime benchmark-browsergym-generalist \
  --profile pr --output /tmp/m82b-generalist-pr
```

The profile is six official MiniWoB task families by three seeds, for 18
episodes. Each episode traverses observation, semantic proposal, deterministic
contract binding, preflight, typed environment action, independent receipt
verification, and official environment grading.

## Results

The final v5 planner prompt run completed all 18 episodes with complete
coverage and no unsupported BrowserGym action:

| Metric | Result |
| --- | ---: |
| Official success / mean official reward | 14/18 (0.7778) |
| Runtime failures | 4 |
| `click-button`, `enter-text`, `click-dialog`, `click-button-sequence` | 3/3 each |
| `choose-list` | 2/3 |
| `form-sequence` | 0/3 |
| Action-family coverage | `click`, `fill`, `select_option` |

The three `form-sequence` episodes stopped with clarification before execution:
their jQuery slider is not represented by the current general semantic action
vocabulary. This is an explicit capability gap, not an unsupported action
hidden as success. The remaining `choose-list` failure was an LM proposal to
activate an invisible `<option>`; BrowserGym rejected it with its official
action error. Prompt version `generalist-planner-v5` adds a generic constraint
that `select_option` targets only a select affordance, never an option/button
whose label happens to match.
