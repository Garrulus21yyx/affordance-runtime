# M8.6 G2.5 Active Perception Execution Plan

Date: 2026-07-23
Status: complete

## Goal and fixed boundaries

Implement the G2.5 exit contract in `current-implementation-plan.md` without
adding a second state writer, benchmark-owned policy, hidden effectful probes,
or online policy mutation. `RunCoordinator` remains the sole phase/state
authority. ActivePerceptionController returns immutable decisions;
PerceptionSession executes only declared read-only observation capabilities.

No benchmark episode matrix, GitHub Action, `.env` access, or push is part of
this implementation phase.

## Initial audit

- Reuse `PerceptionRequirements`, `PerceptionSession.capture_targeted`,
  `SourceAssertionOrchestrator`, `SourceAssertionArbiter`, and coherent
  `BrowserSnapshot` epochs.
- Replace ad-hoc request loops only after equivalent behavior is covered by the
  shared controller.
- Probe transports are adapter capabilities; Core uses generic evidence/source
  types and never BrowserGym task/family/reward vocabulary.
- Scrolling, expanding, opening, clicking, or any state-changing inspection is
  not a probe and must remain an ActionContract.
