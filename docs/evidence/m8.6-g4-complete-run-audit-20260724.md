# M8.6 G4 Complete-Run Audit Evidence

Date: 2026-07-24
Decision: G4 complete; G5 remains pending

## Governance boundary

G4 changes evaluation collection and evidence accounting, not Runtime planning
behavior. It adds no task-family rule, prompt repair, selector, expected answer,
provider special case, or score uplift. BrowserGym remains an external consumer;
the generic `evaluation_audit.py` contract contains no BrowserGym/MiniWoB
identity or scoring vocabulary.

No remote workflow, `.env` access, provider call, browser session, benchmark
episode, or score-producing run was used for this closure. A deterministic
30-case conformance collection exercises the protocol without claiming a
benchmark result.

## Implemented contract

- `EvaluationRunIdentity` canonically binds immutable dimensions and rejects a
  mismatched resume identity.
- `EvaluationRunAudit` reconciles scheduled, observed, failed, Runtime-failed,
  external-failed, unrun, invalidated, and resumed counts against one per-case
  ledger.
- Batch status is one of complete, stopped, incomplete-resumable,
  incomplete-nonresumable, or invalidated. A stop on the final scheduled case
  cannot be mislabeled complete.
- Batch stops are allowlisted by category and explicitly declare whether prior
  observations remain comparable and whether same-identity resume is allowed.
- Resume validates the published typed audit when present. After a hard process
  interruption without a report, atomic checkpoints must form the scheduler's
  observed prefix; only the remaining unobserved cases are selected.
- Identity changes in revision, profile, registry, Prompt, model, schema, or
  budget produce a different digest. BrowserGym v6 checkpoint metadata also
  binds runtime source, Python executable/version, BrowserGym/Playwright
  versions, perception components, and time/model-call budgets.

## BrowserGym consumer behavior

- The protocol version is `three-layer-breadth-first-audit-v2`; schedule remains
  seed-major/breadth-first.
- Ordinary reward-zero, planning-budget, observation, execution, verification,
  grounding, or clarification failures remain case-local and do not stop the
  collection.
- Safety/authority, result/checkpoint corruption, environment/version drift,
  profile-wide persistent provider failure, and source/oracle failure map to
  explicit batch-stop semantics. Unreviewed stop reasons are rejected.
- Checkpoint and final report publication use atomic replace plus file and
  directory synchronization. Foreign, duplicate, renamed, misbound, or
  non-prefix checkpoint evidence is rejected.
- Non-finite external results, negative counters, case/seed mismatches, mixed
  browser versions without drift invalidation, and aggregate/ledger divergence
  fail before report publication.
- Runtime verification outcomes and external evaluator outcomes are reported
  independently. Observed-only score aggregates are labeled as such.
- Formal failure-family and cross-family Runtime-owner clusters are emitted only
  when the collection is complete and comparable. Partial reports retain raw
  failure envelopes but no formal clusters or repair-selection readiness.
- `official_score_claimed` remains false and the promotion gate remains
  `m8.6-g5-open` even for a complete collection.

## Conformance evidence

The deterministic 30-case conformance matrix schedules and observes all 30
cases, includes both Runtime and external failures, reconciles zero unrun and
zero invalidated cases, then emits family and Runtime-owner clusters whose
episode totals equal the failure-envelope total. It proves collection behavior,
not task capability or benchmark performance.

Additional negative tests prove:

- ordinary failures continue;
- incomplete collection is resumable only under the same identity;
- integrity/comparability invalidation cannot resume;
- provider-wide stop may preserve prior comparable cases and resume only the
  unobserved suffix;
- incomplete or tampered evidence cannot publish formal clusters;
- a complete collection with ordinary failures remains complete rather than
  falsely passing.
