# M8.5H v67 Public Matrix Metric Reconciliation

Date: 2026-07-22

## Scope

The controlled M8.5 ablation and live conflict family previously emitted route,
conflict, active-perception, and TaskSkill metrics that the public BrowserGym
nightly/release report could not represent. This slice reconciles the schemas
without running a quota-dependent remote matrix.

## Episode fields added

`BrowserGymEpisodeResult` now carries backward-compatible defaulted fields for:

- route selection count and ordered route sources;
- visual route count;
- fallback route count;
- targeted perception count;
- unresolved/reobserve source-conflict count;
- TaskSkill activation, completion, and fallthrough counts.

The Generalist BrowserGym path derives these values from canonical Coordinator
trace events rather than inferring them from reward or planner output. Existing
checkpoint JSON remains loadable because every new field has a default.

## Report aggregation

`browsergym-report.json` now includes `adaptive_runtime_statistics` with:

~~~text
route_selection_count
route_source_counts
visual_route_count
fallback_route_count
targeted_perception_count
source_conflict_count
task_skill_activated_count
task_skill_completed_count
task_skill_fallthrough_count
~~~

This allows the same route/fallback/conflict/skill decisions measured by the
controlled six-profile ablation to be reported by PR, diagnostic, nightly, and
release BrowserGym matrices. Model-call latency/retry/provider statistics remain
in their existing separate block.

## Validation

- a synthetic trace projection regression covers DOM-to-visual fallback,
  reobserve conflict, targeted perception, and TaskSkill lifecycle events;
- a report-writer regression proves aggregate values and serialized episode
  compatibility;
- 53 focused BrowserGym tests passed;
- full repository gate: `336 passed`;
- full Ruff, focused mypy, script mypy, and `git diff --check`: clean.

No GitHub Actions or provider calls were used. The frozen nightly/release run
itself remains governed by clean immutable source and provider availability;
this slice makes its eventual output M8.5-comparable rather than claiming that
the matrix was executed now.
