# M8.5E v64 TaskSkill System 1 Replay Evidence

Date: 2026-07-22

## Scope

This slice connects a digest-validated accepted `TaskSkill` to the normal
Coordinator as a System 1 fast path. It does not replay primitive macros. Every
step is rebound to the current `UnifiedAffordance`, converted into a fresh
`ActionContract`, and sent through normal route selection, policy, preflight,
execution, post-observation, and verification.

## Runtime behavior proved

- Typed `IntentEntity` values survive compilation into `TaskSpec` and supply
  parameter slots without storing selectors, bids, coordinates, snapshots, or
  approval tokens in the skill.
- `StateKernel` owns the authoritative skill id/version, bindings, active step,
  completed step ids, independent evidence, and fallthrough reason.
- An exact accepted-skill match exposes one semantic step before System 2. A
  successful one-step task completes with zero System 2 planner calls.
- Capability, risk, and approval declarations only constrain reuse. A skill
  cannot add task authority, lower the fresh contract's risk, or bypass the
  normal approval gate.
- A missing or ambiguous current target causes zero action and falls through
  to System 2.
- A later verification failure retains the earlier verified checkpoint, marks
  the skill inactive, and enters the existing `RecoveryIncident` cascade.
  Incident context records skill id/version/step, selected route, failure
  evidence, and preserved completed steps.
