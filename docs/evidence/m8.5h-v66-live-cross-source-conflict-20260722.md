# M8.5H v66 Live Cross-Source Conflict Evidence

Date: 2026-07-22

## Scope

This diagnostic supplies the live discriminating case missing from the
provider-free six-profile ablation. It compares a fixed DOM-first path with the
adaptive SourceAssertion conflict gate in real local Chromium.

The page deliberately begins in a transient disagreement:

- DOM `data-available` says the Save control is available;
- the rendered control is red and its click handler will not apply the effect;
- after 1.2 seconds the rendered control becomes green while the DOM claim
  remains true.

The visual assertion is derived by decoding a full Chromium PNG screenshot and
counting strong red/green pixels. It does not read DOM geometry, a hidden target
box, or planner-authored coordinates.

## Results

Chromium version: `151.0.7922.10`.

| Profile | Runtime | Real effects | Verification | Pixel calls | Targeted observations |
| --- | --- | ---: | --- | ---: | ---: |
| fixed DOM-first | failed | 0 | failed | 0 | 0 |
| adaptive conflict gate | done | 1 | passed | 5 | 1 |

The fixed path bound and executed the current DOM contract immediately. Its
execution receipt was technically successful, but the independent browser
state did not change and postcondition verification failed. Recovery was
disabled for this comparison so the first policy decision remains attributable.

The adaptive path emitted, in order:

~~~text
SourceAssertionsCollected
SourceAssertionsArbitrated
TargetedPerceptionRequested
TargetedPerceptionCaptured
SourceAssertionsArbitrated
ContractBuilt
RouteSelected
PreflightPassed

PostconditionPassed
TaskCompleted
~~~

It performed exactly one bounded targeted observation. After the live pixel
state turned green and agreed with the DOM assertion, the unresolved conflict
was removed, a fresh contract was built, and one real effect was independently
verified. No blind retry occurred.
