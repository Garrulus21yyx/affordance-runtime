## Failure clusters

1. `enter-text-2:seed-3` executed `cherée` for the explicit lowercase transform
   of `CHEREE`; the task terminated with reward 0. This exposed reliance on the
   model for a deterministic string transform.
2. `navigate-tree:seed-7` activated `Leonie` and then `Enola` although hidden
   target `Nathalie` belonged under the tighter `Sergio` subtree. This exposed
   missing deterministic ancestor selection from current container context.
3. `read-table:seed-6` derived visual-only evidence from the field name
   `Color`, then rejected the correct DOM input route with
   `source_not_acceptable`. This exposed an ambiguous keyword in core
   perception requirement derivation.

All three are runtime/planning defects. They are not provider failures, 429s,
model timeouts, or Ollama GPU deployment failures.
