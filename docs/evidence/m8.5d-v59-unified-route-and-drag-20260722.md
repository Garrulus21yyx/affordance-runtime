## Implementation evidence

- `ContractBuilder` resolves `UnifiedAffordance.semantic_target_id` through
  deterministic hard gates and retains the complete `RoutePlan`.
- DRAG contracts carry source and destination semantic IDs, candidate IDs,
  observation epoch, fingerprint key, lease, and shared executor route.
- Preflight checks both gesture endpoints. Contract hash, approval identity,
  and trace bind the dual-target gesture.
- A deterministic candidate execution failure can exclude the failed
  candidate and create a fresh contract with supersession/root lineage.
  Uncertain effects still require state inspection before another action.
- BrowserGym DOM sortable gestures use current viewport geometry and the
  target's leading/trailing insertion half; visual-only gestures retain the
  coordinate fallback. The planner never receives bids, bboxes, or x/y.
- Mixed DOM plus canvas observations retain DOM targets while adding bounded
  visual source/destination regions to the same unified inventory.
- Typed visual-provider failures are propagated to the coordinator instead of
  being silently converted into an empty visual-candidate result.
