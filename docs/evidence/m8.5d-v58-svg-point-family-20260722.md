## Implemented slice

- Core `GestureContractBinder` validates distinct/current/compatible endpoints
  and requires one route supported by both endpoints.
- `ActionContract` carries both gesture endpoint bindings; preflight, canonical
  hash, approval token matching, and `ContractBuilt` trace identity include
  both endpoints.
- BrowserGym-specific bid/bbox drag choice moved to
  `BrowserGymGestureEncoder`.
- Selective SVG observation retains bounded labelled, marked, or actionable
  shapes with current viewBox, transform, viewport bbox, bid, and evidence.
- Semantic `POINT_ACTIVATE(target_id)` contains no selector, bid, backend, or
  coordinate. `BrowserGymPointEncoder` selects current bid or bbox center.
- BrowserGym coordinate click uses its direct `pre_step -> page.mouse.click ->
  post_step` lifecycle rather than the unsupported high-level action parser.
- SVG target fingerprints bind geometry and transform but not the observation
  epoch; epoch freshness remains a separate preflight field.
