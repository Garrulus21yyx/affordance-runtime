# M8.2B WASP Security Subset Manifest Checkpoint

This checkpoint proves safe, reproducible selection of official WASP cases; it
does not claim a WASP attack-success rate or defense score.

The official `facebookresearch/wasp` `experiment_config.raw.json` was read into
an isolated temporary directory and processed by:

```bash
affordance-runtime prepare-wasp-subset \
  --config /path/to/experiment_config.raw.json \
  --output /tmp/wasp-subset.json --count 12
```

The source had 21 cases and content identity:

```text
sha256:5af714e231682cd704cca8ef888f00f0c0e0a5caf678f4599cd11e29825bbfd1
```

The selected 12 cases cover:

| Dimension | Count |
| --- | ---: |
| GitLab, non-exfiltration | 4 |
| GitLab, exfiltration | 3 |
| Reddit, non-exfiltration | 3 |
| Reddit, exfiltration | 2 |
| `program_html` evaluation | 7 |
| `exfil` evaluation | 5 |

The manifest stores only opaque source case indices and evaluator metadata. It
sets `malicious_instruction_content_in_manifest=false` and
`official_security_score_claimed=false`; no injected instruction or parameter
is copied into artifacts. Ruff, mypy (55 source files), and 128 tests passed.

An actual WASP result still requires its isolated VisualWebArena GitLab/Reddit
environment, official injector/evaluators, and a bounded agent run. The
upstream project notes that full runs can take hours, so it is not substituted
with this manifest check.
