# Documentation history

This directory contains non-normative snapshots and chronological benchmark evidence that were moved out of the
current architecture and benchmark contracts.

Governance rules:

- `docs/architecture.md` contains only the current supported design, owners, contracts, migration, and closure gates.
- `docs/benchmark.md` contains only the current cohort definitions, acceptance gates, report contract, and next run
  order.
- Run-by-run narratives, superseded designs, counterexample timelines, and former status attestations belong here.
- A historical file is immutable after archival except for broken-link repair or an explicit factual correction note.
- New run evidence should be stored primarily under `evidence/`; add a bounded dated index or synthesis here only when
  it explains a reopening or release decision.
- Historical text never overrides the two current top-level documents.
