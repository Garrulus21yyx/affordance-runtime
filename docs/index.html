The thesis

项目解决的不是“模型不会点”，而是“谁有权相信什么”

一个普通通用模型可以提出不错的下一步，但不能天然拥有当前页面事实、元素寿命、执行权限、动作副作用或任务完成真值。Harness 的工作，是把这些非认知问题机械化，让模型只做它擅长、也只能由开放世界推理完成的部分。

Model owns

语义判断

理解目标、判断当前缺什么证据、在当前公开工具里选一个动作、处理开放世界歧义；GoalPlan 只是稀疏语义骨架。

Runtime owns

控制与真值

合法性、currentness、私有 binding、风险确认、执行 receipt、局部效果、Checkpoint、Monitor 与终止状态。

Evaluator owns

完成证明

只有 TaskEvaluator 或环境 native verifier 能证明任务成功；Monitor、用户与 Runtime 仍可分别产生 blocked、cancelled、failed 等非成功终态。

The harness rail

一次决策如何穿过整个系统

点击 owner 过滤器，观察每个角色真正拥有的节点。关键约束是：只有 ActionPolicy 能选择可执行语义动作；GoalCompiler 与 VLM 只提供静态建议或证据，没有第二个 planner、binder 或视觉旁路，所有路径回到同一个 CoreAgentLoop。

Supervised autonomy

用户不是旁观者，而是外部控制平面

Pause / Cancel

采用协作式 safe boundary。Pause 在可提交边界生成 durable checkpoint；Cancel 终止未来动作，但不会假装撤销已经发生的外部效果。

Revise

修订产生新的 TaskGoal revision，旧 GoalPlan 失效并重编译。若已有副作用，先进入显式 effect reconciliation，而不是把新目标覆盖旧现实。

Take over

先 durable pause，再签发 process-local control lease。用户可直接操作 live surface；Agent 此时没有输入权。

Return control

先撤销用户 lease，再重新采集 fresh World。若 currentness 无法恢复，Agent 保持禁用，避免在过期页面上继续。
