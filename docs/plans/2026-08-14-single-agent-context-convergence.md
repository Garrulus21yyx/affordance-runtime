# Single-agent context convergence plan

Date: 2026-08-14

Status: `IMPLEMENTED / LOCALLY_VERIFIED / PUSHED_E7F9F46 / LIVE_NOT_RUN`

## Goal

Converge the grounded GUI policy to one internal context owner and one main
Agent decision call per Runtime turn. Remove the mandatory task-state updater
chain without weakening Unified World, public E-ref grounding, legal tool
compilation, private binding, admission, execution or authoritative evaluation.

## Causal model

The repository already owns a complete bounded `AgentContext`. The grounded
catalog then projects a second context-shaped `ToolPolicyView`; the context
binder projects that view again; and `eb19c0d` added a mandatory structured
task-state model call before the actor. This confused three responsibilities:

- `AgentContext`: the sole internal model-context state;
- tool catalog: public tool schemas plus opaque Runtime bindings;
- model binder: the sole internal-state-to-provider-message conversion.

The two-call slice repaired a local belief/action ordering issue but introduced
a new mandatory schema gate. The clean `cdb4bc9` diagnostic showed 7/7 initial
updater responses required repair and 4/7 repairs still failed before the actor.
This is shared evidence of a context-ownership and projection problem, not a
reason to add another repair or cognition stage.

## Target contract

1. `AgentContext` is the only internal task/world/progress/history/pending/
   budget context owner.
2. One `GroundedPolicyContextBinder` creates the provider messages directly
   from that context and the current public tool catalog.
3. The action catalog owns only public tool schemas, call-local E-ref mappings
   and opaque private action bindings; it does not own another task context.
4. One main Agent model call chooses one current public tool. Provider/schema
   repair may correct that same tool response but may not introduce a semantic
   planner or updater.
5. Runtime retains action legality, currentness, private binding, execution,
   observation, evidence lineage and final task evaluation.
6. No task name, benchmark case, page text, fixed ID, color/count rule or
   task-family branch may enter production code.
7. Existing advisory `AgentWorkingMemory` must not be regenerated by a
   mandatory pre-action model call. Any retained compatibility state is only a
   bounded context field, not a second world or action authority.

## Non-goals

- no critic, classifier, second planner or LocalObjective restoration;
- no new provider abstraction or generalized context framework;
- no benchmark rerun in this implementation slice;
- no deletion of Runtime control history, Unified World or public grounding;
- no claim that one-call cognition is benchmark-closed before fresh evidence.

## Falsifiable exit criteria

- a grounded action turn makes one semantic model call in the valid path;
- the model input contains original task, current Unified World, Runtime
  transition/history, progress/pending/budget context and current tools through
  one binder;
- task-state updater prompts, payloads, repair counters and mandatory calls are
  absent from the action path;
- public tools still resolve through current E-ref to opaque action binding;
- objective and action static types remain separate;
- architecture tests reject a reintroduced updater or second context owner;
- focused and full validation, Ruff, mypy and wheel resource checks pass.
