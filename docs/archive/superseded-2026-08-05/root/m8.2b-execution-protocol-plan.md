## 2026-07-22 visual BrowserGym binding smoke

An explicit visual fallback is now available only with `--visual-grounding`.
When structured controls are absent, the planner receives one opaque,
screenshot-bound semantic target; it never receives coordinates. The contract
binder validates the screenshot pixels, snapshot/page revision, point bounds,
and BrowserGym action schema before emitting `mouse_click`. Visual mode also
selects BrowserGym's `miniwob_all` action subset; the ordinary bid-only path is

The `grid-coordinate` seed-0 smoke reached an accepted `mouse_click` with no

executed-but-unverified visual pattern as `grounding_unverified` at

limitation, not evidence to tune a task prompt. The next generic layer is a
bounded visual region/mark proposal route for precise spatial and gesture

## Non-negotiable run semantics

- Smoke/PR Gate is six tasks by one seed and may stop only for a batch circuit
  breaker.
- Diagnostic Sweep is thirty tasks by one or two seeds. It completes despite
  ordinary task failures, then clusters failure envelopes for one repair
  decision.
- Frozen Nightly is the versioned thirty-task manifest by ten seeds, scheduled
  seed-major. It records every ordinary episode failure and performs analysis
  only after the batch completes.
- `--resume` is permitted only when immutable run metadata matches exactly;
  code, prompt, schema, context policy, model, or budget changes require a new
  output directory.
- Checkpoint v5 binds a digest of runtime source, launcher, package metadata,
  and pinned requirement files. It deliberately excludes `.env`, artifacts,
  and documentation: secrets never enter metadata, while any executable source
  change invalidates `--resume`. Both `nightly` and `release` reject a dirty
  worktree before episode execution.
