Conversion audit · 05 perceive & act

页面信号如何变成一次受控动作

DOM、accessibility、视觉和设备信号先被融合为一致快照，再投影成目标；typed interaction 经过 grounding 和 choice filtering，最后绑定为快照相关的 ActionContract。

← 上一章：Loop返回总览下一章：验证 →

本页结论：从丰富页面到单个动作会发生连续降维：原始信号 → 统一目标 → 当前候选 → 唯一合同。每次降维都可能漏掉真实目标，因此 ambiguity、conflict、freshness 与 snapshot binding 必须显式保留。

DOM / AX / Visual / Device→BrowserSnapshot→UnifiedObservation→GroundingCandidate→ActionChoice→ActionContract→ExecutionReceipt
05-A

多源页面信号 → BrowserSnapshot

输入 INPUT

DOM/AX tree、截图/标记/OCR、SVG geometry、设备属性、API 状态及 perception requirements。

→

输出 OUTPUT

一个 coherent BrowserSnapshot：Observation、source observations/assertions、grounding candidates、arbitration decisions 与 artifacts。

转换者与规则：PerceptionSession.capture 调 BrowserSession；targeted capture 要求所有 source observation/assertion/candidate 共享同一 observation epoch。
原始信号操作快照表示损失
DOM/AX nodes规范化affordances/assertions样式/脚本细节可能省略
截图像素产物化 + 识别artifact ref + visual evidence像素不直接进入结构字段
多源冲突仲裁decision/conflict未选断言不作为当前事实
时间变化epoch 绑定snapshot_id/revisions跨 epoch 信号禁止混合

保留语义

来源、当前性、冲突、证据类型、目标指纹和产物引用。

可能的语义损失

动态动画、被遮挡内容、非可访问 DOM、OCR 错误、样式关系与捕获间瞬时变化；仲裁会让低优先来源退出当前事实。

风险与防护

同 epoch coherence、source-local confidence、conflict codes、EvidenceGap 和只读 active probes 防止伪融合。

失败出口

缺证据、stale、source conflict 或 ambiguous entity 转 active perception/blocked，而非直接动作。

05-B

BrowserSnapshot → UnifiedObservation

输入 INPUT

PlannerObservationView：snapshot/page/environment revision、observed_text、affordances、artifact refs。

→

输出 OUTPUT

target-centric UnifiedObservation，每个 target 含 id/surface/role/label/actions/state/confidence/conflicts/source refs。

转换者与规则：UnifiedObservation.from_planner_observation 把 affordance tuple 映射成不可变 target tuple，并强制 target ID 唯一。

保留语义

目标语义、可执行动作、状态、置信与冲突、来源和三类 revision。

可能的语义损失

原始 adapter-specific 属性、完整 DOM 层级、视觉空间细节和 source assertion 全文可能只剩 target state/source refs。

风险与防护

不同节点被归一为同一 target 时可能合并过度；唯一 ID、conflict codes 和 source refs 允许追溯。

失败出口

空 revision、重复 target ID、非法 confidence/blank source refs 在构造时失败。

05-C

InteractionIntent + Observation → GroundingCandidate / ActionChoice

输入 INPUT

Element/Collection/Relation/Region Intent、active step scope、当前 targets 与 permitted action kinds。

→

输出 OUTPUT

resolved/ambiguous/absent/capability_missing grounding，以及 Runtime-owned ActionChoice 集合。

转换者与规则：interaction_grounding.py 按 typed relation 匹配；ActionChoiceBuilder 过滤不支持动作、非当前候选、scope 未授权和 terminal 未 ready 的目标。
Intent 语义操作候选字段损失点
role/label/relation语义匹配target_id/candidate_id近义或隐式关系可能不匹配
ordinal/collection窗口解析position/route分页全局序数可能不确定
region/spatial几何绑定point/target fingerprint截图缩放/移动影响位置
allowed actions交集过滤action kinds未授权动作被有意删除

保留语义

当前目标、支持动作、typed relation、scope evidence、来源、目标指纹和 snapshot identity。

可能的语义损失

未匹配/低置信目标完全退出 choice set；自由视觉关系被有限 InteractionIntent 表达；候选过滤可能出现假阴性。

风险与防护

不允许模型绕过候选集；0/ambiguous 会显式失败并触发 targeted perception/reground。

失败出口

resolved 才可继续；ambiguous/absent/capability_missing 分别进入消歧、重观测或能力失败。

05-D

PlannerProposal → ActionContract / preflight

输入 INPUT

选中的 action/target/parameters、active step criterion IDs、当前 observation、policy/capabilities。

→

输出 OUTPUT

绑定 run/snapshot/page/step 的 ActionContract，含 intent、locator/gesture、expected effect、risk、capabilities、approval/idempotency/compensation。

转换者与规则：ActionStage 的 _bind 调 ContractBuilder；随后 scope/policy/capability/approval/lease/snapshot preflight，且立即重观测。

保留语义

动作意图、目标身份、参数、预期效果、验证准则、安全要求和当前页面绑定。

可能的语义损失

Planner 的自然语言理由不会成为合同权威；locator 是当前 candidate 的具体绑定，其他替代目标丢失；审批只覆盖一个具体 contract hash/capability。

风险与防护

页面在 proposal 后变化会使合同陈旧；preflight reobserve、lease/fingerprint 与审批后再验证阻断。

失败出口

policy/capability denied、approval required、stale snapshot、scope rejected 分流到 user/recovery/terminal。

05-E

ActionContract → Executor result → ExecutionReceipt

输入 INPUT

已 authorize 的合同及原子动作参数。

→

输出 OUTPUT

ExecutionReceipt：contract lineage、executor status/error、底层 evidence、是否 dispatched 与时间信息。

转换者与规则：ContractExecutionLoop/executor dispatch；receipt 只陈述执行层观察，不生成任务完成权威。

保留语义

哪个合同被尝试、是否发出、执行器错误、局部返回值与底层证据。

可能的语义损失

浏览器/OS/API 的丰富副作用被压成有限 receipt；超时时真实外部效果可能已发生但未知；success 不包含业务后验状态。

风险与防护

receipt 与 verification 分离；timeout 映射为 may_have_occurred，禁止盲目重放非幂等动作。

失败出口

not_dispatched 可安全恢复；execution_uncertain 先 inspect post-state；irreversible/unknown 可能交给用户。

本页语义损失账本

转换边类型损失/不确定控制
Raw signals → Snapshot观测不确定遮挡、动态、OCR/adapter 误差coherent epoch + gaps
Snapshot → Unified targets规范化降维adapter/层级/像素细节source refs + artifacts
Intent → Choices候选收缩未 grounded/未授权目标typed failure + re-perception
