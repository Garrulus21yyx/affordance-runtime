# World Interaction Capability Migration Plan

## Scope

Selectively migrate validated capabilities from
`/home/yang/projects/A-Modular-Action-System-Architecture` into this repository.
Reuse observe/ground/route/execute/verify/evaluate capabilities and environment
assets. Do not import the legacy global controller, mutable CognitiveMap,
RecoveryCascade, ledger authority, or global state machine.

`origin/feature/C-009-unify-runtime-architecture@c3d85f5`.
